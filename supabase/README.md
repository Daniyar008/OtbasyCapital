# Supabase базасын дайындау

`migrations/20261027_001_finance_tables.sql` файлын Supabase SQL Editor-де
немесе қосылған DBeaver SQL редакторында толық скрипт ретінде орындау керек.
DBeaver-де файлды ашып, **SQL Editor → Execute SQL Script** әрекетін таңдаңыз.
Бір SQL операторын орындау бүкіл файлды орындаумен бірдей емес.

Соңғы SELECT бес кестені және әрқайсысы үшін `rls_enabled = true` көрсетуі тиіс.
Скрипт бұрынғы жазбаларды жоймайды. Қате болса, транзакция толық аяқталмайды;
қатені түзетпей бөлек операторларды қолмен орындамаңыз.

Кестелер: `otbasy_families`, `otbasy_members`, `otbasy_entries`,
`otbasy_goals`, `otbasy_reminders`.

Құрылым жергілікті модельдердің мәтіндік ID-лерін сақтайды. `user_id` Supabase
Auth аккаунтына тиесілі; құрамдас сыртқы кілттер басқа аккаунттың отбасына
немесе қатысушысына сілтеме жасауға жол бермейді. Әзірге әр аккаунт өзінің
жергілікті отбасы деректерін сақтайды. Нақты ортақ отбасылық рұқсат бөлек
мүшелік моделімен кейін іске асырылуы керек.

Қолданбаға publishable key және жүйеге кірген пайдаланушының сессиясы қажет.
Publishable key жалғыз өзі кестелерді оқуға немесе өзгертуге рұқсат бермейді.
PostgreSQL паролін не service_role/secret key-ді Flutter кодына енгізуге болмайды.

Бұл файл бұлттық қосылу аяқталды дегенді білдірмейді: алдымен скриптті нақты
базада орындап, кейін Auth пен қосымшадағы синхрондауды қосу қажет.
Hive жергілікті сақтау үшін қолданыла береді.
