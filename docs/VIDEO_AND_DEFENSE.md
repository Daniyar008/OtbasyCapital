# «Отбасы капиталы» — 3–4 минуттық видео және қорғау мәтіні

## Видеоға дейін

1. Render-дегі сайтты Chrome-да ашыңыз және аккаунтқа кіріңіз.
2. Браузер терезесін 1920×1080 етіп қойыңыз.
3. Экранды `Win + Alt + R` арқылы немесе OBS Studio арқылы жазыңыз.
4. Төмендегі мәтінді CapCut-тағы Text to Speech функциясына бөліктермен қойыңыз.
5. Баяу емес, анық қарқын таңдаңыз. Музыканы қоспауға немесе өте бәсең қоюға болады.

## 0:00–0:25 — Жобаны таныстыру

**Экран:** кіру экраны, кейін басты бет.

**Озвучка:**

«Сәлеметсіздер ме. Менің жобам — “Отбасы капиталы” мобильді және веб-қосымшасы. Жобаның мақсаты — отбасының кірісін, шығысын, жинақ мақсатын және төлем еске салғыштарын бір жерде бақылау. Қосымша Flutter арқылы жасалды, ал деректер Supabase серверінде сақталады.»

## 0:25–0:55 — Басты бет және бюджет

**Экран:** басты бет, “Ортақ” және “Жеке” ауыстырғышы, ай фокусы, жедел батырмалар.

**Озвучка:**

«Басты бетте ағымдағы қалдық, кіріс және шығыс көрсетіледі. Пайдаланушы ортақ немесе жеке көріністі таңдай алады. “Ай фокусы” ең көп шығын кеткен санатты және төлем еске салғыштарын көрсетеді. Жедел батырмалар арқылы операция, мақсат немесе еске салғыш бірден ашылады.»

## 0:55–1:35 — Операциялар және чек

**Экран:** “Операция” → жаңа шығыс қосу → санат, сома, ескертпе → сақтау → тарих.

**Озвучка:**

«Қазір жаңа шығыс операциясын қосамын. Атауын, сомасын, санатын және қажет болса ескертпесін енгіземін. Чек болса, камерадан немесе галереядан сурет тіркеуге болады. Сақтағаннан кейін операция тарихында көрінеді, ал қалдық автоматты түрде қайта есептеледі. Операцияны кейін өзгертуге, таңдаулыға қосуға немесе жоюға болады.»

## 1:35–2:05 — Лимит, мақсат және еске салғыш

**Экран:** “Айлық бюджет” → “Айлық лимитті өзгерту” → сома енгізу → мақсат → еске салғыш.

**Озвучка:**

«Айлық бюджет бөлімінде жалпы лимит пен санаттар бойынша шығын көрінеді. “Айлық лимитті өзгерту” арқылы қолданушы өз сомасын енгізеді, ал санат лимиттері соған сай қайта есептеледі. Мақсаттар бөлімінде жинақ мақсатына үлес қосуға болады. Еске салғыштар төлем күнін ұмытпауға көмектеседі.»

## 2:05–2:45 — Отбасылық чат және ЖИ

**Экран:** отбасылық чат → қарапайым хабарлама → `@көмекші осы айдағы ең көп шығын қандай?` → жауап.

**Озвучка:**

«Қосымшада отбасылық чат бар. Хабарлар уақыт бойынша реттеліп, жаңа хабарлар төменде пайда болады. Чатты қажет болғанда тазалауға болады. “@көмекші” деп жазып, бюджет бойынша сұрақ қоюға болады. Сұрақ Supabase Edge Function арқылы Gemini сервисіне жіберіледі. ЖИ жауабы чатта қаржы көмекшісі ретінде шығады.»

## 2:45–3:20 — Сервер, қауіпсіздік және қорытынды

**Экран:** архитектура диаграммасы, содан кейін басты бет немесе презентацияның соңғы слайды.

**Озвучка:**

«Архитектурада Flutter клиенті Supabase API-мен байланысады. Supabase Auth кіруді орындайды, PostgreSQL деректерді сақтайды, Storage чек суреттеріне қолданылады, ал Realtime чат пен операциялардың жаңаруын қамтамасыз етеді. Gemini кілті мобильді кодта сақталмайды, ол серверлік Edge Function secrets ішінде болады. Жобада CRUD, авторизация, камера, хабарландыру, бұлттық база, Realtime және ЖИ мүмкіндіктері біріктірілді. Назар қойып тыңдағандарыңызға рақмет.»

## 7-сабақ бойынша қысқа жауап

«Жетінші сабақта Supabase Auth, Google OAuth кіруіне арналған код, Realtime чат және Gemini ЖИ көмекші қосылды. WebSocket байланысы Supabase Realtime арқылы жасалды. ЖИ сұрауы тікелей Flutter-ден емес, Edge Function арқылы жіберіледі.»

## 8-сабақ бойынша қысқа жауап

«Сегізінші сабақта барлық модульдер біріктірілді. Интерфейс жақсартылды, бюджет лимитін өзгерту, чат хабарламаларын реттеу және тазалау қосылды. Тест-кейстер, Bug Report, пайдаланушы нұсқаулығы, архитектура диаграммасы және web build дайындалды. `flutter analyze` қатесіз өтті, автоматты тесттер сәтті аяқталды.»

## Егер мұғалім кодты сұраса

| Не көрсету | Файл | Қысқа түсіндіру |
|---|---|---|
| CRUD және есептеу | `lib/app/app_store.dart` | Операцияны қосу, өзгерту, жою және қалдықты есептеу осы жерде. |
| PostgreSQL REST API | `lib/core/services/supabase_finance_service.dart` | GET, POST, PATCH, DELETE сұраулары Supabase клиенті арқылы орындалады. |
| ЖИ | `lib/core/services/ai_chat_service.dart`, `supabase/functions/ai-chat/index.ts` | Flutter сұрақты Edge Function-ға жібереді, ал функция Gemini-ден жауап алады. |
| Realtime чат | `lib/features/chat/services/family_chat_service.dart` | Stream жаңа хабарларды алып, уақыт бойынша сұрыптайды. |
| Бюджет лимиті | `lib/features/budget/screens/budget_screens.dart` | Қолданушы айлық лимитті өзі өзгерте алады. |
