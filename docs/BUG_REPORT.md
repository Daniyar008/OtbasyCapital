# Bug Report

## BR-01 Чек сақтағанда Storage bucket табылмады

- Маңыздылығы: жоғары
- Қайталану қадамы: операция формасын ашу, чек фотосын таңдау, сақтау.
- Күтілетін нәтиже: фото Storage-ге жүктеледі.
- Нақты нәтиже: `Bucket not found` қатесі шықты.
- Себебі: `receipts` bucket әлі жасалмаған.
- Түзету: Storage bucket және access policy migration арқылы қосылды.
- Қайта тексеру: фото жүктеу сценарийі сәтті өтті.

## BR-02 JPEG файл түрі қабылданбады

- Маңыздылығы: орташа
- Қайталану қадамы: `.jpg` чек файлын таңдау.
- Күтілетін нәтиже: JPEG файл жүктеледі.
- Нақты нәтиже: `image/jpg is not supported` қатесі шықты.
- Себебі: қате MIME type жіберілген.
- Түзету: `.jpg` және `.jpeg` үшін `image/jpeg` қолданылды.
- Қайта тексеру: JPEG файл жүктеледі.

## BR-03 Realtime ағыны үзілгенде экран жаңармады

- Маңыздылығы: жоғары
- Қайталану қадамы: желіні өшіру, Realtime stream қатесін күту.
- Күтілетін нәтиже: offline күйі және қайта қосылу әрекеті көрінеді.
- Нақты нәтиже: алдыңғы нұсқада байланыс күйі анық көрсетілмеді.
- Түзету: `RealtimeState.offline` және 5 секундтық reconnect timer қосылды.
- Қайта тексеру: интернет қосылғаннан кейін stream қайта іске қосылады.

## BR-04 Gemini модель қатесі

- Маңыздылығы: орташа
- Қайталану қадамы: чатта `@көмекші` деп сұрақ жіберу.
- Күтілетін нәтиже: ЖИ жауабы келеді.
- Нақты нәтиже: бұрынғы lite модельге 502 жауап келді.
- Түзету: Edge Function ішіндегі модель атауы қолжетімді нұсқаға ауыстырылды.
- Қайта тексеру: Supabase secrets пен Edge Function deploy орындалғаннан кейін жүргізіледі.
