# Практикалық жұмыс №4

Берілген тапсырма: жергілікті база, модельдер және деректермен жұмыс.

## Модельдер

| Модель | Өрістер мен типтер | Байланысы |
|---|---|---|
| Family | id: String, name: String | Бір отбасыда бірнеше қатысушы |
| FamilyMember | id, familyId, name: String | familyId → Family.id |
| MoneyEntry | id, familyId, ownerId, title, category, owner, note: String; amount: int; income, shared, favorite: bool; date: DateTime | familyId → Family.id; ownerId → FamilyMember.id |
| SavingsGoal | id, familyId, ownerId, title, owner: String; target: int; date: DateTime; shared: bool; contributions: Map<String,int> | Отбасы мен иесі; үлес кілті - қатысушы аты |
| PaymentReminder | id, familyId, title: String; date: DateTime; monthly, done: bool | familyId → Family.id |

Бір жергілікті отбасы қолданылады: family-main. Жаңа операция ID-і уақыттан жасалады.
Бұрынғы жазбаларды байланыстыру үшін қатысушы ID-і өзгермейтін атынан есептеледі.
Атты өзгерту функциясы жоқ. Нақты көппайдаланушылық жүйеге бөлек тұрақты UUID және серверлік рұқсаттар қажет.
Ақша бүтін теңгемен, күндер сақтау кезінде ISO 8601 жолымен беріледі. Құпиясөздер базаға жазылмайды.

## Қорғауда көрсету

1. Бастау → Кіру. Басты беттегі қалдықты көрсету.
2. Тарих → Magnum → Өзгерту. 5000 орнына 4000 енгізу: қалдық 226000 болады.
3. Таңдаулыларға қосу. Іздеу → «Сүзгі және сұрыптау».
4. «Азық-түлік», «Шығыс», «Сома: көптен азға» таңдау.
5. Сүзгілерді тазалау. Жаңа операция құрып, оны жоюды көрсету.
6. Сол браузер мен адресті қайта ашып, сақталған деректерді көрсету.
7. Модельдер, FinanceRepository және lesson4_storage_test.dart кодын түсіндіру.

өзгертуге және жоюға болады. Іздеу, сүзгілеу және сұрыптау жергілікті деректермен жұмыс істейді.
Базаны қайта ашқанда операциялар мен таңдаулылар сақталады. Қате болса, қосымша оны хабарлайды».
