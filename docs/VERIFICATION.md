## Тексеру шектері

Нақты Android телефонында қайта іске қосу тексерілмеді. Орнатылған NDK 28.2.13676358 папкасында
source.properties файлы жоқ; Android SDK орнатуын аяқтау қажет. APK дайын деп көрсетілмейді.

Браузерлік сақтау әр адреске бөлек. Қалыпты браузер режимінде бір адресті пайдалану керек.
Сайт деректерін тазаласа, жергілікті база да жойылады. Жүйенің бүкіл интернет қосылымы өшірілген жоқ:
желісіздік тестте HTTP-ге тыйым салу арқылы тексерілді.

Оқу аккаунты серверде тексерілмейді. Жеке жазбаларды бөлу - жергілікті демонстрация,
толық пайдаланушы қауіпсіздігі емес. Нақты төлем, хат жіберу, push және бұлттық синхрондау қосылмаған.

## Web жинағы

Release web жинағы сәтті орындалды. Рендерлеу ресурстары жергілікті жиналды (--no-web-resources-cdn).
Wasm үйлесімділігін алдын ала тексеру де өтті; таратылатын жинақ - стандартты JavaScript нұсқасы.
