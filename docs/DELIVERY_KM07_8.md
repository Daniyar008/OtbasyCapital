# КМ07 ПО — 8-сабақ: тапсыру құрамы

Бұл файл соңғы тапсырмаға жиналған материалдарды тез тексеру үшін берілген.

## Дайын материалдар

- бастапқы код: `lib/`, `test/`, `assets/`, `supabase/`;
- интерфейс, авторизация, CRUD, Supabase REST API, сурет/камера, Realtime чат және ЖИ көмекші;
- 18 тест-кейс: `FINAL_TEST_CASES.md`;
- қате есебі: `BUG_REPORT.md`;
- архитектура: `ARCHITECTURE.md`;
- пайдаланушы нұсқаулығы: `USER_GUIDE.md`;
- 2–3 минуттық көрсету мәтіні: `DEMO_SCRIPT.md`;
- презентация: `output/presentation/KM07_8_Otbasy_kapitaly_Daniyar_final.pptx`.

## Тексеру нәтижесі

- `flutter analyze` — қате жоқ;
- `flutter test` — 41 тест сәтті өтті;
- `flutter build web --release --no-web-resources-cdn` — сәтті жиналды.

## Қалған екі әрекет

1. Android Studio ішінен NDK 28.2.13676358-ді қайта орнатып, APK жинау.
2. `DEMO_SCRIPT.md` бойынша экран жазбасын түсіру.

Бұл екі әрекеттің нақты себебі мен командалары `APK_BUILD_STATUS.md` файлында көрсетілген.
